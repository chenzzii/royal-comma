# Claude Code — 第二階段：接續實作 v4.1（Execute Mode）

使用者已同意依照已審查的計畫繼續開發。請離開 Plan Mode，**直接修改現有原始碼，而不是另起專案**。

## 工作重點
1. 保留 v4.0 的玩法：沒有「本回合委託」；任意位置放逗號但只有兩個隱藏合法位置；錯位重寫+1混亂；較高混亂選擇+180分、較低+65分；混亂7亡國；八關結束；隨機種子；原創配樂、結局下載。
2. 把 `docs/ROADMAP.md` 中 P1「先前選擇影響後面宮廷反應」做到可玩：至少四組明確的因果事件，例如熊公主、魔界聯姻、巨龍餵養、國王直播賣藥、王子親自執法等；讓玩家在後續的**判決畫面**立即看到，不要只放在最後《王國正史》。
3. 將關聯邏輯封裝成純函式（可從歷史推得確定結果），避免互斥時序矛盾與重複觸發。不要求引入大型框架。
4. 保留音樂的滑稽無力感，以及從來源檔 build 成可雙擊玩的單一 HTML 形式。
5. 當新劇情影響既有結局時，調整最後《王國正史》避免重複敘述或矛盾。

## 驗收
- 新增測試覆蓋至少四組跨關分歧及先後順序，並驗證原版 16 項測試仍通過。
- `npm test`、`npm run build` 必須真正執行。
- 如有瀏覽器環境，至少跑八關勝利、七次錯位亡國與兩種關卡順序的宮廷連鎖事件；手機上檢查長篇內容與逗號操作。
- 每次修改後寫入 `docs/PROGRESS.md`，列出真實測試證據；不能把計畫中的功能說成已完成。
- 不要上傳雲端、push、部署，除非我另外明確要求。

完成後請交代變更檔案、哪些事件真正能在遊戲裡觸發、測試結果、未完成／未驗證項目，以及產生的遊戲 HTML 路徑。
