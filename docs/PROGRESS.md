- `src/app.mjs`：新增一次性過場 `cut` 與 `cutscene()`。開始或接續一章時顯示章節標題卡（章名、規則、可用符號，接續時加註「前情延續」），約 2.1 秒，點一下即可略過；蓋章時一顆大印章砸下（核准為紅色「准」、退件為灰色「退」），畫面輕震；換頁時頁面淡入，羊皮紙浮上；結局時「，？！」從天上落下（勝利是彩色，失敗是灰色）。動畫結束後元素自行移除。頁尾版號改為 v4.6。
- `src/styles.css`：新增 v4.6 區塊，全部用 CSS 動畫，沒有新增素材。開啟「減少動態效果」時完全不播。
- 過場只出現在章節開頭或蓋章之後，不提供任何答案資訊。除章節標題卡外都不攔截點擊。
- 瀏覽器腳本 v41、v42、v43 在量測按鈕尺寸前會等標題卡結束；新增 `scripts/browser-verify-v46.py`。
## 修正
- 印章原本用回彈曲線 `cubic-bezier(.3,1.6,.5,1)`，`visibility` 被插值成 hidden，結果印章整段看不見。已改用 ease-out，回彈改寫在關鍵影格裡。
- 羊皮紙原本從右側滑入，在手機上播放時會出現水平捲動。已改成由下往上浮出。
## 實際執行
- `npm test`：44 項通過；`npm run build` 成功。
- `browser-verify-v4/v41/v42/v43/v46.py` 全部通過。截圖：`docs/v46-chapter-card.png`、`docs/v46-stamp.png`。
