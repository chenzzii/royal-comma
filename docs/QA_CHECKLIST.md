## 驗證環境限制
- `scripts/browser-verify-v4.py`、`browser-verify-v41.py` 需要 Python Playwright；預設使用 Playwright 內建 Chromium，或以 `CHROMIUM_PATH` 指定。
- Playwright 自動執行過**音樂解碼及 play() 調用**，沒有感官評斷的能力；真人聆聽結果須另填。
- 尚無公開網址部署測試或全平台實機手測。
