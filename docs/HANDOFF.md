# Claude Code 接手說明 — 《國王的遺囑只有一個逗號》v4.0

交接日期：2026-10-26（臺灣）  ｜  基準版本：v4.0「荒謬宮廷史版」

## 1. 遊戲定位
- 繁體中文單機黑色幽默文字解謎，舞台是已駕崩的國王仍不肯停止下令的宮廷文書局。
- 玩家是一名皇家書記官。**不能改原文，只能在任意一個字界放置一個全形逗號**；依據標點位置執行命令，產生荒謬的政治與人物後果。
- 使用者偏好：不是提示答案的選擇題，而是有推理難度、荒謬但具因果連鎖的劇情；配樂要有無力、笨拙、喜劇性的宮廷感，不能像壯烈史詩。

## 2. 開發歷程與明確決策
- v1：8 關、兩個完整備選答案、「本回合委託」、御印系統 → **使用者認為太簡單**。
- v2：逗號可以插在任何位置；僅兩個隱藏有效位置；錯位退件 +1 混亂、同關重寫；補充「熊公主」等荒誕後果。
- v3：**徹底移除本回合委託與預揭露答案**，改由玩家推測哪種解讀更混亂；高風險 +180 分，保守 +65 分，混亂 7 亡國；背景改為完整樂曲。
- v4：依照使用者提供的直笛、彈撥、笨拙低音的滑稽音樂**氣氛**另行原創約 66.6 秒 BGM；新增 8×2 = 16 段選擇後果、12 條跨關事件、事件順序差異、成功／亡國兩種收尾；允許複製結局及下載 TXT。
- 不得把 v1 的「御印／本回合委託」當成現有機制重新加入；那是已被淘汰的設計。

## 3. v4 實際玩法
- 每局 8 關，順序由 seed 決定；同 seed 可重現相同關卡順序。
- 每關原文只有兩個可解讀的預設有效逗號位置，但是 **UI 允許句首、句尾及所有字間位置**；有效位置不提示。
- 選到非有效位置：這份命令無法執行，混亂 +1、0 分、退回同一關重寫。
- 有效解讀：高混亂選擇 +180 分；低混亂選擇 +65 分。每種有自己的 `chaosDelta`、語意、標題、短劇情及後日談。
- 初始混亂 0；任何結果混亂不低於 0；達到 7 或以上立即失敗。若八關都完成且未亡國則勝利，依剩餘安全空間另給結算獎勵。
- 兩個有效位置不一定一個一定 + 混亂、一個一定 - 混亂；比較的是**當關兩個合法結果的相對混亂度**。
- 勝利分數使用 `pointsRisky/pointsCautious` 加上 `endBonusPerSafety * (7-chaos) + endBonusPerCorrectDecree * 8`；以 `content/levels.json` 及 `src/engine.mjs` 為唯一事實來源。
- 每關選擇一旦蓋章不可重填，失敗時重做的只有該關尚未執行的退件。

## 4. 敘事引擎現況
- `content/levels.json`：8 關原文、2 合法逗號位置、當關結果、混亂值與宮廷短劇情。
- `src/epilogue.mjs`：16 段 `CHRONICLE` 分支段落、12 組 `CROSSOVERS` 條件（可依先後順序另寫變體）、開場與勝敗收尾。
- `makeChronicle(game)` 根據歷史產出標題、開場、三幕故事、跨關段落及尾聲；包含退件次數及敗北原因。
- 256 種「8 關各選一種合法結果」的**選擇組合**經單元測試產生不同文字結果；這不等於 256 篇獨立人工編寫的劇本，也不涵蓋所有不同關卡順序／退件路線的手寫對應故事。
- 目前跨關段落上限顯示 4 條，更多匹配的事件沒有顯示；未來應檢查資訊流、劇情重複與因果合理性。
- 現在主體是「結局回顧所有選擇」，遊戲中途的後續關卡對先前事件仍缺乏真正改變的台詞／角色狀態，這是優先擴充方向。

## 5. 音樂 / 音效
- 活躍 BGM：`audio/tired_royal_march.mp3`，約 66.6 秒，建置時以 base64 內嵌入單檔 HTML；在玩家互動後播放，循環。
- 規格：笨重行進低音、彈撥伴奏、滑稽高音笛聲；帶有「公務員精疲力盡但仍維持禮貌」的感覺。
- 使用者提供的《帝国进行曲 (直笛版).mp3》只供**感覺參考**，不在交接包中；禁止直接放入產品或摹寫其辨識性旋律。
- 蓋章、退件等是程式合成音效（見 `src/app.mjs`），使用者可分別開關 BGM/音效。
- BGM 是否有無縫循環接點、不同瀏覽器自動播放限制、實際音色觀感，仍需真人聆聽驗證。

## 6. 畫面與體驗
- 羊皮紙、酒紅背景、金色王冠、蓋章動畫、宮廷判決、長篇結局與 TXT 匯出。
- 可以鍵盤與滑鼠操作，手機 390px 排版已通過自動化溢出檢查。
- 無需登入與外部伺服器；本機最高分、音效設定、種子用 localStorage 保存。**整局中途進度不保證刷新續玩**。

## 8. 最重要的接手原則
- **先審查、再修、再擴充**，不要大量重構後才發現遊戲不能玩。
- 不把作弊提示（顯示兩個正確位置、回合委託）加回去。
- 重點不是增添更多笑話，而是建立「本局玩家做過的荒唐決定 → 後續角色行為 → 不同結局」的可檢驗因果鏈。
- 維持當前可下載、無依賴、可離線玩的單檔 HTML，除非使用者另要求改變部署方式。
