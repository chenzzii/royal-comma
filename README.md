# 《國王的遺囑只有一個逗號》v4.0 — 荒謬宮廷史版

繁體中文、可離線遊玩、無需安裝的單頁 HTML 遊戲。單檔內包含所有劇情、程式與原創音樂。

## v4 新功能
- 背景音樂：《無力的皇家遊行》（暫定），約 66.6 秒、4/4 拍。滑稽笛聲、輕快彈撥和笨重低音，取材自使用者提供音檔的**氣氛**，完全重新創作旋律與編曲；沒有使用來源的音訊取樣或旋律。
- 依所有已執行聖旨產生完整的王國史：每個有效解讀有獨立故事段落（8 關 × 2），以實際關卡順序編成三幕，包含可觸發的跨關後日談（12 種）。
- 先結婚再救魔王，和先救魔王再結婚，跨關後日談不一樣。
- 通關與敗北有不同的結局收尾；敗北會指出實際造成亡國的最後一份命令。
- 故事可以複製，或下載成 UTF-8 TXT。逐關歷史另外摺疊收起。
- 16 項 Node 測試包含 256 種有效選擇組合的故事差異驗證。

## v3 保留規則
- 八關；可將一個逗號插入句首、句尾或任兩字之間，只有兩個隱藏位置能形成可執行的命令。
- 沒有回合委託、沒有事先提示答案。放錯位置：混亂 +1、必須重做該關。
- 有效解讀之中風險較高得 180 分，較安穩得 65 分。混亂達 7 即亡國；完成八關且未亡國則勝利。
- 相同種子得到相同關卡順序；背景音樂和蓋章特效音可獨立開關。

## 遊玩
雙擊 `國王的遺囑_可玩版.html`，使用 Chrome / Edge 開啟。音樂需在使用者點擊「開始」後播放（瀏覽器限制）。

## 程式碼
- `src/engine.mjs`：遊戲規則
- `src/epilogue.mjs`：16 段原創故事、12 項跨關事件、劇情先後與結局生成器
- `src/app.mjs`：介面、操作、聲音與結局
- `src/styles.css`, `src/shell.html`：版面及視覺
- `content/levels.json`：8 關劇本與數值
- `audio/tired_royal_march.mp3`：原創配樂（可獨立試聽）
- `scripts/make-bgm.py`：原創音樂合成腳本（重做音樂需 NumPy 和 FFmpeg）
- `scripts/build.mjs`：打包成單檔 HTML
- `scripts/browser-verify-v4.py`：實際 Chromium 遊玩自動測試
- `tests/`：Node 測試

`npm test` / `npm run build` / `npm run dev` （Node 18+，無第三方 npm 套件）。

## 驗證範圍
- 16 項程式測試通過，256 種組合呈現互不相同的結局內文（透過作者撰寫的獨立分支段落組合，不代表人工逐一寫出 256 篇完整小說）。
- Chromium 測試：錯位退件、八關通關、七次退件亡國、熊公主聯姻特殊後日談、複製與 TXT 下載、手機結局顯示。
- 音樂嵌入式 MP3 時長約 66.6 秒，玩家點擊後觸發 `play()`；實際在不同喇叭上的音色尚未由使用者實際試聽。
- 瀏覽器自動測試透過 `page.set_content` 載入，尚未測試雲端部署網址。
